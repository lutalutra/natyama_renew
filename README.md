# Natsumi Sugiyama — Portfolio

Static HTML/CSS/JS portfolio starter.

## Start
Open `index.html` locally, or enable GitHub Pages for the repository.

## Replace content
- Project images: `assets/images/`
- Main layout: `index.html`
- Featured cases: `projects/`
- Styling: `assets/css/main.css`
- JP/EN/DE strings: `assets/js/i18n.js`

The current grey image blocks are intentional placeholders.
